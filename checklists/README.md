## How to use them every day

1. Open a new Claude session in this folder and say, for example:
   *"Show me today's options from the checklists"* — Claude reads the four
   lists and suggests 2–3 tasks from the **current milestone** whose
   *needs* are done.
2. Pick your tasks. Claude does the 🤖 ones; you do the 🧑 ones; 🤝 you do together.
3. When a task is finished, it gets ticked **in the same session**:
   `- [x] **DEV-01** … — done 2026-10-01`
4. Start with the ⛔ tasks — they block launch.

**Key:** 🧑 you · 🤖 Claude · 🤝 both · ⛔ blocks launch ·
*needs* = must be finished first.
