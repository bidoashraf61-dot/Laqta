# لقطة — دليل الصانع ومواصفات التسليم

**مسودة للاعتماد · ٢٦ سبتمبر ٢٠٢٦ · ALB-20**
النسخة الإنجليزية: [creator-brief-en.md](creator-brief-en.md) · نموذج سجل الجودة: [qa-log-template.csv](qa-log-template.csv)

لقطة مكتبة لقطات للسعودية. المشترون — مونتيرون مستقلون ووكالات — يشترون
**ألبومات كاملة** بدفعة وحدة وترخيص دائم، بلا اشتراك. هذا الدليل فيه كل
اللي تحتاجه عشان يعدّي ألبومك المراجعة من أول مرة.

---

## ١. عرض الصنّاع المؤسسين

| | |
|---|---|
| حصتك | **٧٠٪ من كل عملية بيع** لألبومك |
| السعر | تحدده لقطة عند الاعتماد، **من ٤٩ إلى ٢٤٩ دولار للألبوم**، حسب عدد اللقطات وجودتها |
| الأرباح | بالدولار، متى وصل رصيدك المتاح **١٠٠ دولار**. كل عملية بيع تصير متاحة بعد **٣٠ يوم** من الشراء |
| طريقة الاستلام | حساب بنكي (IBAN) أو Wise أو Payoneer — تختار من الاستوديو |
| الحقوق | غير حصرية: حقوق النشر تبقى لك، ولك تبيع اللقطات في مكان ثاني |
| الموعد النهائي | تسليم الألبوم قبل **[التاريخ — يحدده المالك في ALB-23]** |

## ٢. وش هو الألبوم

- **موضوع واحد.** فكرة أو مكان أو نشاط واحد — مثل «البلد في جدة ليلاً»،
  «ثقافة القهوة»، «الصحراء والإبل». نتفق معك على الموضوع قبل ما تبدأ، عشان
  ما تتكرر الألبومات.
- **من ٣٠ إلى ٧٠ لقطة.** الاستوديو ما يقبل الإرسال بأقل من ٣٠ أو أكثر من ٧٠.
- **مصدر واحد.** الألبوم إما **كله مولّد بالذكاء الاصطناعي** أو **كله تصوير
  حقيقي**. لا تخلط بينهم، ولا تعرض لقطات مولّدة على أنها تصوير حقيقي.
- **اتجاه واحد.** كله أفقي ١٦:٩، أو — في ألبوم عمودي مخصص — كله عمودي ٩:١٦.
- **بلا حشو.** لا لقطات شبه متطابقة عشان تكمّل العدد.

## ٣. المواصفات التقنية

كل لقطة في الألبوم لازم تطابق باقي لقطاته. اختلاف معدل الإطارات أو اللون
يخلّي الألبوم ما يشتغل على خط زمني واحد — وهذا أكثر سبب نرجّع فيه الألبومات.

| | المطلوب |
|---|---|
| الدقة | **1920×1080 كحد أدنى**، و4K مرحّب فيها. سلّم الدقة اللي أنتجتها فعلاً — **لا لقطات مكبّرة صناعياً ولا باهتة**. دقة وحدة لكل ألبوم |
| معدل الإطارات | معدل **واحد** لكل ألبوم: 24 أو 25 أو 30 إطار في الثانية |
| اللون | مظهر لوني **واحد** لكل ألبوم. Rec.709 للقطات المولّدة؛ التصوير الحقيقي يكون LOG أو Rec.709 — مو الاثنين. خلّ التلوين محايد عشان يقدر المشتري يعدّله |
| الطول | **من ٥ إلى ٢٠ ثانية** للقطة. لا مقاطع ثانيتين |
| الصوت | **بدون صوت** — اكتم المسار أو احذفه |
| نوع الملف | `.mov` أو `.mp4` |
| الترميز | H.264 أو H.265 (HEVC) أو ProRes |
| حجم الملف | حتى **20 جيجابايت** للملف |
| الجودة | واضحة، ثابتة، إضاءتها سليمة. بلا إطارات ساقطة ولا تكسّر ضغط ولا وميض |

## ٤. الدقة السعودية — وش يراجع المراجِع

المشتري يدفع عشان لقطات شكلها سعودي فعلاً. المراجِع يرفض اللقطة اللي تغلط
في هذا.

- **اللبس:** الثوب والغترة/الشماغ والعقال بلبسة صحيحة؛ العباية والحجاب
  بأسلوب سعودي، مو من بلد ثاني. لبس محتشم في كل اللقطات.
- **الأماكن:** العمارة والطبيعة والنباتات تطابق المنطقة المذكورة (الطين
  النجدي غير الحجر المنقبي الحجازي).
- **الشوارع:** السير على اليمين؛ لوحات سيارات بالشكل السعودي؛ لوحات الطرق
  بالعربي والإنجليزي.
- **النصوص:** أي كتابة عربية في اللقطة — لوحات، واجهات محلات، تغليف — لازم
  تكون **صحيحة ومقروءة**، أو ما تكون موجودة أصلاً. أدوات الذكاء الاصطناعي كثير
  تخترع حروف عربية بلا معنى، وهذي اللقطات ترفض.
- **التصرفات:** سلوك مناسب للسوق السعودي.

### فحوصات إضافية للقطات المولّدة بالذكاء الاصطناعي

- الأشخاص لازم يكونون **خياليين**. لا شبه لشخص حقيقي أو مشهور أو شخصية عامة.
- افحص كل لقطة من أخطاء الذكاء الاصطناعي: أصابع زايدة أو ملتصقة، وجوه تذوب،
  أشياء تتحول، حركة مستحيلة، خلفيات ترمش.
- **لازم خطة أداتك تسمح لك تبيع الناتج تجارياً كلقطات مخزون.** احتفظ بنسخة
  مؤرخة من شروط الأداة؛ ممكن نطلبها.
- سجّل الأداة المستخدمة لكل لقطة في سجل الجودة.

### متطلبات إضافية للتصوير الحقيقي

- **تصريح نموذج** لكل وجه واضح (ترفعه في الاستوديو).
- **تصريح ملكية** للأماكن الخاصة أو التجارية.
- **تصريح تصوير** للمواقع اللي تشترطه — العلا (الهيئة الملكية)، الدرعية،
  نيوم، البحر الأحمر، المطارات وغيرها. التصريح لازم يغطي تواريخ التصوير
  والموقع بالتحديد، ويذكر الجهة المصدِرة.

## ٥. ما لا نقبله

- الحرمين الشريفين (مكة والمدينة) — تصوير حقيقي أو مولّد.
- المنشآت العسكرية أو الحكومية أو الحدودية أو الأمنية.
- الكحول والقمار وكل ما يمنعه نظام المملكة.
- الأماكن والشعائر الدينية بشكل غير لائق؛ الرموز الدينية أو الوطنية في سياق
  تجاري يسيء لها.
- أي شي ممكن يُفهم سياسياً أو أمنياً.
- شعارات تجارية بارزة، أو منتج معروف هو موضوع اللقطة. شعار صغير غير واضح في
  الخلفية ما فيه مشكلة.
- أعمال فنية أو لوحات محمية بحقوق وتحتاج إذن.
- لقطات ما تملك حقوقها كاملة، أو مأخوذة من إنتاج غيرك.
- لقطة موجودة أصلاً في لقطة، أو إعادة رفع لألبوم مرفوض.

## ٦. تسمية الملفات

```
<اسم-الألبوم-المختصر>_<الرقم>_<وش-تعرض>.mov
jeddah-balad-night_001_lantern-alley-wide.mov
jeddah-balad-night_002_coffee-pour-closeup.mov
```

حروف إنجليزية صغيرة، شرطة بدل المسافة، رقم من ثلاث خانات.

## ٧. سجل الجودة

عبّ سطر لكل لقطة في [qa-log-template.csv](qa-log-template.csv) وأرسله مع
ألبومك. يخلّي المراجِع يراجع ألبومك مرة وحدة بدل ما يرجع لك بأسئلة.

| العمود | وش تكتب |
|---|---|
| file_name | اسم الملف مثل ما رفعته بالضبط |
| origin | `ai` (مولّد) أو `filmed` (تصوير حقيقي) |
| tool_or_camera | مثل `Seedance 2.0` أو `Kling` أو `Sony FX3` |
| location_shown | المدينة أو الموقع اللي تعرضه اللقطة |
| resolution, fps, codec | مثل `3840x2160` و`25` و`ProRes 422 HQ` |
| duration_s | طول اللقطة بالثواني |
| people | `none` (بلا أشخاص)، `fictional (ai)` (خياليون)، `unidentifiable` (غير واضحين)، `identifiable` (واضحون) |
| release_or_permit | رقم التصريح، أو `not needed` |
| on_screen_text | `none`، أو وش مكتوب |
| self_check | `pass`، أو الخطأ اللي لقيته |

## ٨. كيف تمشي الأمور

١. **قدّم** — أرسل من ٣ إلى ٥ لقطات عيّنة أو رابط أعمالك. نختار الصنّاع على
   أساس الجودة والدقة السعودية والالتزام.
٢. **التجربة** — سوّ **٥ لقطات** على الموضوع المتفق عليه بهذي المواصفات.
٣. **الاتفاق** — توقّع اتفاقية الصانع، ويتثبت موضوعك وموعدك.
٤. **الألبوم** — من ٣٠ إلى ٧٠ لقطة، مع سجل الجودة.
٥. **الرفع** — أنشئ الألبوم في استوديو لقطة (الواجهة بالعربي) وارفع اللقطات
   والتصاريح.
٦. **المراجعة** — خلال **٣ أيام عمل**. يا يُعتمد، يا يرجع لك مع أسباب المراجِع.
٧. **النشر** — لقطة تحدد السعر وتنشر الألبوم، ولك ٧٠٪ من كل عملية بيع.
