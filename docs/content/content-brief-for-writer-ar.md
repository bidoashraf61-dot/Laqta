# لقطة — موجز الكتابة وهيكل الموقع الكامل

**المهمة:** اكتب المحتوى العربي لكل صفحة في الموقع، حسب الهيكل في القسم الرابع.
اقرأ الموجز أولاً — فهم النموذج التجاري ونبرة الصوت شرط لأي سطر تكتبه.

---

## ١ · الموجز التجاري

### ما هي لقطة

مكتبة لقطات فيديو سعودية. تُباع على شكل **ألبومات** — مجموعة لقطات متجانسة حول
قصة أو موقع واحد — لا لقطة مفردة، ولا اشتراك شهري.

### النموذج التجاري

| | لقطة |
|---|---|
| طريقة الدفع | دفعة واحدة، تملك الألبوم للأبد |
| وحدة البيع | ألبوم كامل جاهز للمونتاج (١٠–٢٤ لقطة) |
| الترخيص | **ترخيص تجاري واحد**، بلا حد للمشاهدات، بلا تاريخ انتهاء |
| المحتوى | سعودي، مصوّر في الموقع أو مُنتَج بالذكاء الاصطناعي |
| العملة | الدولار الأمريكي |
| السعر | يبدأ من ٧٩ دولاراً للألبوم الصغير |

**نقطة حرجة:** لا يوجد إلا ترخيص واحد. أي نص يلمّح إلى «ترخيص قياسي» أو «ترخيص
موسّع» أو حد للمشاهدات هو نص خاطئ.

**لا تذكر أي منافس بالاسم، ولا تقتبس رقماً عن منافس، ولا تقارن بمنصة محددة.**
المقارنة المسموحة هي مع البديل الواقعي: يوم تصوير.

### الجمهور — أربعة مشترين وصانع محتوى

١. **وكالات الإعلان** — تنفّذ حملات لعلامات سعودية، وتحتاج مواد لا تحتاج اعتذاراً
   عن مصدرها.
٢. **الجهات الحكومية وشبه الحكومية** — تحتاج فاتورة ضريبية، أمر شراء، تحويل بنكي،
   وتصاريح موثّقة.
٣. **فرق التسويق الداخلية** — تريد مكتبة تغنيها عن يوم تصوير لكل حملة.
٤. **شركات الإنتاج والمستقلون** — يحتاجون لقطات ربط ومشاهد تأسيسية بمواصفات
   متناسقة.

وعلى الجهة الأخرى **صنّاع المحتوى** الذين يبيعون عبر المنصة: مصوّرون، ومشغّلو
درون، وصنّاع أفلام بالذكاء الاصطناعي.

## ٢ · نبرة الصوت

واثقة، دقيقة، وسعودية الأذن. المبدأ الحاكم: **كل جملة تقول حقيقة يمكن التحقق
منها.** لا مبالغة، ولا صفات مركّبة، ولا لغة شركات.

### قاعدة السجل اللغوي — أهم قاعدة في هذا الملف

**حين تخاطب القارئ مباشرة: لغة سعودية منطوقة.**

> «عندك أرشيف لقطات؟» · «وش تحتاج؟» · «ما فيه شي هنا بعد» · «سلتك فاضية»

**حين تقرّر حقيقة أو تسمّي مصطلحاً: فصحى واضحة.**

> «ترخيص تجاري كامل، بلا حد على عدد المشاهدات»

هذا التقسيم هو ما يمنع الموقع من أن يبدو مترجماً. **لا توحّد السجلين.**

⚠️ في مراجعة سابقة حُوّلت كل العبارات المنطوقة إلى فصحى رسمية — «سلتك فاضية»
صارت «سلتك فارغة»، و«وش تحتاج؟» صارت «تفاصيل المشهد المطلوب». هذا أسوأ ناتج
ممكن: نص سليم نحوياً وميت الأذن. الحالات الفارغة، والأسئلة الموجهة للقارئ،
ونداءات الفعل الشخصية — كلها تبقى منطوقة.

### أخطاء يجب ألا تظهر

| النمط | مثال مرفوض | لماذا |
|---|---|---|
| رقم عن منافس | «أرخص بـ١٦ مرة» | لا يمكن إثباته |
| حجم ألبوم مخترع | «٣٠ أو ٥٠ لقطة» | الكتالوج ١٠–٢٤. العدد يُقرأ من البيانات |
| كلمة من قطاع آخر | «بثقة واستدامة» | لا معنى لها هنا |
| ترجمة حرفية | «دقيقة الثقافة» | نقل حرفي لـ culturally accurate |
| تكرار المعنى | «متناغمة… متكاملة… موحّد» | ثلاثة مرادفات لفكرة واحدة |
| صفة بلا مضمون | «قصتك البصرية الكاملة» | لا أحد يقول هذا |
| حشو متكرر | «مصمّمة خصيصاً» ×٥ | مرة اختيار، خمس مرات تلعثم |
| وعد لا نملكه | «تعويض قانوني» · «دعم ٢٤/٧» | لم يُقرّ بعد |

### مصطلحات ثابتة — كلمة واحدة لكل معنى

| المعنى | الكلمة |
|---|---|
| وحدة البيع | ألبوم |
| القطعة الواحدة | لقطة |
| من يبيع على المنصة | صنّاع المحتوى |
| الترخيص | ترخيص تجاري كامل |
| ما تحصل عليه بعد الدفع | امتلاك دائم للأبد |
| طريقة الدفع | ادفع مرة واحدة · بلا اشتراكات |
| الطائرة | درون |
| فيلم الألبوم القصير | التريلر |
| الملف الجاهز للمونتاج | نسخة المونتاج |

## ٣ · قيود تقنية

- `{name}` و`{count}` و`{album}` متغيّرات — **انقلها كما هي بلا تغيير ولا حذف.**
  حذف `{count}` يزيل الرقم من البطاقة.
- **الجمع العربي:** ما يأتي بعد رقم يُكتب مفرداً من ١١ فأكثر — «١٢ لقطة» لا
  «١٢ لقطات». الكتالوج ١٠–٢٤ لقطة، فاستخدم المفرد بعد الأرقام دائماً.
- الأرقام هندية (٢٢) في النص التحريري، ولاتينية في الأسعار والمواصفات.
- أوصاف محركات البحث لا تتجاوز **١٦٠ حرفاً**.
- **نصوص الأزرار كلمة أو كلمتان.** الأزرار لها عرض محدود ونص طويل يكسر التصميم.
- عناوين الصفحات (H1) سطر واحد قصير — تُعرض بخط كبير جداً.
- الموقع ثنائي اللغة (عربي/إنجليزي). اكتب العربية فقط؛ الإنجليزية تُترجم لاحقاً.

## ٤ · هيكل الموقع الكامل — ٥٦ صفحة، أربعة أقسام

اكتب محتوى كل صفحة. اذكر اسم الصفحة ثم النصوص المطلوبة تحتها.

### أ · الواجهة العامة (للزوار والمشترين)

| الصفحة | المحتوى المطلوب |
|---|---|
| **الرئيسية** | عنوان رئيسي (سطران: تمهيد + جملة عريضة)، نص تعريفي، زرّان. ثم ١١ قسماً: المشكلة والحل، جدار اللقطات، المجموعة، الترخيص، كيف تعمل (٣ خطوات)، السعر والقيمة (٣ نقاط)، الأسئلة الشائعة (٥)، اطلب لقطة، نداء ختامي، دعوة صنّاع المحتوى |
| **/albums** الألبومات | عنوان، وصف، حالة فارغة |
| **/albums/[صانع]/[ألبوم]** صفحة الألبوم | عناوين الأقسام: التريلر، اللقطات، المواصفات، الترخيص، ألبومات ذات صلة، التقييمات |
| **/footage** اللقطات | عنوان، وصف، أسماء عوامل التصفية، نص «لا نتائج» |
| **/footage/[لقطة]** صفحة اللقطة | تسميات المواصفات، شارة «ذكاء اصطناعي / تصوير واقعي»، نص العلامة المائية |
| **/collections** المجموعات | عنوان، وصف |
| **/collections/[مجموعة]** | عنوان، وصف |
| **/categories/[تصنيف]** | عنوان، وصف |
| **/locations/[موقع]** | عنوان، وصف |
| **/creators** صنّاع المحتوى | عنوان، وصف |
| **/creators/[صانع]** ملف الصانع | تسميات الإحصاءات، «ألبومات مختارة»، حالة بلا تقييمات |
| **/sell** بِع لقطاتك | عنوان، مقدمة، معايير القبول (٤)، آلية العمل (٤ خطوات)، ما يصنع ألبوماً جيداً (٦ قواعد)، الحقوق، الأسئلة الشائعة (٤) |
| **/licences** الترخيص | شرح الترخيص الواحد: ما يشمله، ما لا يشمله |
| **/cart** السلة | عنوان، حالة فارغة **بلغة منطوقة**، أزرار |
| **/checkout** إتمام الشراء | تسميات الحقول، طرق الدفع، رسائل النجاح والانتظار |
| **/about** عن لقطة | القصة، لماذا وُجدت، الفريق |
| **/contact** تواصل معنا | عنوان، تسميات النموذج، وعد بمدة الرد |
| **/terms** الشروط | نص قانوني كامل |
| **/privacy** الخصوصية | نص قانوني كامل |
| **/refunds** الاسترجاع | لا استرجاع بعد التحميل؛ سبعة أيام قبله |
| **/content-policy** سياسة المحتوى | الإفصاح عن الذكاء الاصطناعي، استثناء المواقع الدينية، حظر الاستخدام الإخباري |
| **/sign-in** · **/sign-up** | عناوين، تسميات، رسائل خطأ |
| **/forbidden** | رسالة «لا تملك صلاحية» |
| **/boards/[رابط]** لوح مشارَك | عنوان، وصف للمستلم |

## ٥ · كيف تسلّم العمل

- سلّم **كل** الصفحات. المراجعة السابقة غطّت نصف الموقع وتركت لوحة التحكم
  وحساب المشتري بلا محتوى.
- رتّب التسليم بنفس ترتيب القسم الرابع، وبنفس أسماء الصفحات.
- لكل صفحة: اذكر اسمها، ثم كل نص تحتها مع وصف قصير لمكانه
  (مثال: `العنوان الرئيسي:` … `نص الزر:` …).
- إذا احتاج نص متغيّراً، اكتبه بالصيغة نفسها: `{count} لقطة`.
- إذا رأيت أن صفحة تحتاج نصاً لم أذكره، أضفه واشرح مكانه.
