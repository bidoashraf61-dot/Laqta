# لقطة — محتوى الموقع بالكامل للمراجعة اللغوية

> **إلى المحرّر:** هذا ملف مرجعي كامل لكل نص عربي في الموقع.
> اقرأ الموجز أولاً — فهم النموذج التجاري ونبرة الصوت شرط لأي تعديل.
> ثم أعد الملف **بنفس البنية ونفس المفاتيح** مع النص المحسّن فقط.

---

## ١ · الموجز التجاري

### ما هي لقطة

مكتبة لقطات فيديو سعودية. تُباع على شكل **ألبومات** — مجموعة لقطات متجانسة
حول قصة أو موقع واحد — لا لقطة مفردة، ولا اشتراك شهري.

### النموذج التجاري — وهو ما يميّزها

| | لقطة | المكتبات العالمية |
|---|---|---|
| طريقة الدفع | دفعة واحدة، تملك الألبوم للأبد | اشتراك شهري ينتهي |
| وحدة البيع | ألبوم كامل جاهز للمونتاج | لقطة مفردة |
| الترخيص | ترخيص تجاري واحد، بلا حد للمشاهدات | درجات وتراخيص متعددة |
| المحتوى | سعودي، مصوّر في الموقع أو مُنتَج بالذكاء الاصطناعي | عام، غالباً ليس سعودياً |

**نقطة حرجة:** لا يوجد إلا ترخيص واحد. أي نص يلمّح إلى «ترخيص قياسي» أو
«ترخيص موسّع» أو حد للمشاهدات هو نص خاطئ يجب حذفه.

### الجمهور

١. **وكالات الإعلان** — تنفّذ حملات لعلامات سعودية وتحتاج مواد لا تحتاج اعتذاراً عن مصدرها.
٢. **الجهات الحكومية وشبه الحكومية** — تحتاج فاتورة ضريبية وأمر شراء وتصاريح موثّقة.
٣. **فرق التسويق الداخلية** — تريد مكتبة تغنيها عن يوم تصوير لكل حملة.
٤. **شركات الإنتاج والمستقلون** — يحتاجون لقطات ربط ومشاهد تأسيسية بمواصفات متناسقة.

وعلى الجهة الأخرى **صنّاع المحتوى** الذين يبيعون عبر المنصة: مصوّرون،
ومشغّلو درون، وصنّاع أفلام بالذكاء الاصطناعي.

### نبرة الصوت

**واثقة، دقيقة، وسعودية الأذن.** المبدأ الحاكم: كل جملة تقول حقيقة يمكن
التحقق منها. لا مبالغة، ولا صفات مركّبة، ولا لغة شركات.

قاعدة السجل اللغوي — وهي مقصودة ويجب الحفاظ عليها:

- **حين نخاطب القارئ مباشرة:** لغة سعودية منطوقة.
  «عندك أرشيف لقطات؟» · «وش تحتاج؟» · «ما فيه شي هنا بعد»
- **حين نقرّر حقيقة أو نسمّي مصطلحاً:** فصحى واضحة.
  «ترخيص تجاري كامل، بلا حد على عدد المشاهدات»

هذا التقسيم هو ما يمنع الموقع من أن يبدو مترجماً. **لا توحّد السجلين.**

### أخطاء يجب ألا تعود

سبق أن حُذفت هذه الأنماط من الموقع بعد مراجعة. لا تُعدها:

| النمط | مثال حُذف | لماذا |
|---|---|---|
| رقم عن منافس | «أرخص بـ١٦ مرة من أي منافس» | لا يمكن إثباته، ولا نذكر المنافسين |
| حجم ألبوم مخترع | «٣٠، ٥٠، أو ٧٠ لقطة» | الكتالوج ١٠–٢٤ لقطة. العدد يُقرأ من البيانات |
| كلمة من قطاع آخر | «بثقة واستدامة» | لا معنى لها هنا |
| ترجمة حرفية | «دقيقة الثقافة» | ليست عربية — نقل حرفي لـ culturally accurate |
| تكرار المعنى | «متناغمة … متكاملة … موحّد» | ثلاثة مرادفات لفكرة واحدة |
| صفة بلا مضمون | «قصتك البصرية الكاملة» | لا أحد يقول هذا |
| حشو متكرر | «مصمّمة خصيصاً» ×٥ | مرة اختيار، خمس مرات تلعثم |

### مصطلحات ثابتة — كلمة واحدة لكل معنى

| المعنى | الكلمة |
|---|---|
| وحدة البيع | ألبوم |
| القطعة الواحدة | لقطة |
| من يبيع على المنصة | صنّاع المحتوى (بالشدّة) |
| الترخيص | ترخيص تجاري كامل |
| ما تحصل عليه بعد الدفع | امتلاك دائم للأبد |
| طريقة الدفع | ادفع مرة واحدة · بلا اشتراكات |
| الطائرة | درون |
| فيلم الألبوم القصير | التريلر |

### قيود تقنية

- `{name}` و`{count}` وما شابه **متغيّرات** — انقلها كما هي بلا تغيير.
- الأرقام تُكتب هندية (٢٢) في النص التحريري، ولاتينية في الأسعار والمواصفات.
- أوصاف محركات البحث (`seo`) لا تتجاوز ١٦٠ حرفاً.
- نصوص الأزرار قصيرة — كلمة أو كلمتان. الأزرار لها عرض محدود.

## ٢ · كيف تُعيد الملف

أعد **نفس البنية بالضبط**: نفس العناوين، ونفس المفاتيح، وبنفس الترتيب.

كل سطر على الصورة التالية — لا تغيّر المفتاح، غيّر النص بعد الشرطة فقط:

```
- `landing.heroLead` :: محتوى سعودي أصيل،
```

**مهم:**

١. إن كان النص سليماً، أعده كما هو. لا تُعدّل لمجرد التعديل.
٢. لا تحذف مفتاحاً ولا تضف مفتاحاً جديداً.
٣. إن رأيت نصاً يخالف الموجز أعلاه، صحّحه واذكر السبب في قائمة
   «ملاحظات» في آخر الملف.
٤. لا تترجم المفاتيح ولا أسماء الأقسام الإنجليزية.

## ٣ · المحتوى

### الهوية ووصف الموقع لمحركات البحث

*اسم العلامة ووعدها، وأوصاف الصفحات التي تظهر في نتائج جوجل. الوصف لا يتجاوز ١٦٠ حرفاً.*

- `brand.name` :: لقطة
- `brand.tagline` :: مكتبة اللقطات السعودية
- `brand.promise` :: ألبومات لقطات سعودية بترخيص تجاري كامل. تدفع مرة واحدة وتمتلكها للأبد، بلا اشتراكات.
- `brand.forWhom` :: لصنّاع المحتوى والشركات، ولكل من يعمل على علامة سعودية أو حملة تخص المملكة.
- `brand.seo.home` :: ألبومات لقطات سعودية جاهزة للمونتاج بدقة عالية، أفقية ورأسية. محتوى سينمائي سعودي يوفّر عليك ساعات الإنتاج، بترخيص تجاري كامل ودفعة واحدة للأبد بلا اشتراكات.
- `brand.seo.licences` :: ترخيص واحد لكل ألبوم: تجاري كامل، بلا حد على عدد المشاهدات، ويشمل الحملات المدفوعة والعرض خارج المنزل والمنتجات المعدّة لإعادة البيع. دائم، ولا ينتهي بتاريخ.
- `brand.seo.about` :: محتوى سينمائي سعودي يُباع على شكل ألبومات جاهزة، بترخيص تجاري كامل ودفعة واحدة للأبد، وبسعر يقدر عليه المستقل العربي. تعرّف على القصة والفريق.
- `brand.seo.contact` :: تواصل معنا لطلب لقطات لموقع محدد، أو للاستفسار عن تفاصيل الترخيص والفواتير وحسابات الوكالات. نرد خلال يوم عمل واحد.
- `brand.seo.terms` :: الشروط والأحكام التي تحكم استخدام المنصة وشراء الألبومات: الطلبات والدفع والتحميل وحدود المسؤولية والقانون الواجب التطبيق.
- `brand.seo.privacy` :: كيف نجمع بياناتك ونستخدمها ونحميها: البيانات التي نطلبها، ومدة الاحتفاظ بها، وحقوقك، وطريقة التواصل معنا بشأنها.
- `brand.seo.refunds` :: سياسة الاسترجاع: لا يوجد استرجاع بعد تحميل أي ملف من الألبوم. قبل التحميل، لك سبعة أيام لطلب استرجاع كامل المبلغ.
- `brand.seo.contentPolicy` :: ما الذي يُقبل رفعه وبيعه على المنصة: الإفصاح الإلزامي عن المحتوى المولّد، واستثناء المواقع الدينية، وحظر الاستخدام الإخباري.
